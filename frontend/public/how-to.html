How to convert a PDF

The same PDF uploader can create an EPUB for reading or spreadsheet files for working with text and tables.

1. Create a free account

Open the converter, choose Start converting, then register or sign in. Authentication protects conversion downloads and your personal EPUB library.

2. Choose the output

Select EPUB to preserve the visual PDF pages. Select Excel to create a readable XLSX workbook with one worksheet per page and formatted table cells.

3. Upload the PDF

Drag the PDF onto the upload area or use the file picker. The current free limit is 50MB and 50 pages.

4. Download the result

EPUB conversion provides an EPUB download and saves the book in your library. Excel export provides a readable XLSX document, one combined table CSV, and a ZIP with separate CSV files for detected tables.

Which format should I use?

Use EPUB when page appearance matters. Use XLSX when people need to read and edit extracted content. Use CSV when software needs clean table rows.
