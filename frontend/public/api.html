How do I convert a PDF without signing in?

Send the PDF to the public conversion API. No account and no token are required. The same free limits apply: 50MB and 50 pages. One address can start 8 conversions per hour. The result is not saved to a library.

Base URL: https://pdf-converter-api-gateway.onrender.com. The first call can take about a minute while the free server wakes up.

1. Start a conversion

POST /api/public/convert with a multipart file field named file. Optional form field output is epub (default) or excel. Excel returns an XLSX workbook, plus CSV and ZIP downloads when tables are found. 

curl -F "file=@document.pdf" -F "output=epub" \
  https://pdf-converter-api-gateway.onrender.com/api/public/convert

The response includes conversion_id and status: processing.

2. Wait for the result

GET /api/public/status/{conversion_id} until status is completed. A completed EPUB response includes download_url. A completed Excel response can also include tables_download_url and archive_download_url.

3. Download the file

GET /api/public/download/{conversion_id} returns the EPUB or XLSX. Add ?kind=tables for the combined CSV or ?kind=archive for the ZIP of separate tables. These links work only for jobs created by the public API.
