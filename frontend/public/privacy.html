Privacy information

This page explains the current data flow of the open-source PDF conversion application.

Account information

Registration and authentication are provided through Supabase. The application uses your account identifier and email address to protect downloads and associate EPUB books with your library.

Uploaded PDF files

PDFs are sent to the conversion service for processing. Temporary input files are removed after the conversion job finishes. Do not upload a document if you are not authorized to process it.

Generated files

EPUB files saved to the personal library can be stored through Cloudinary, while library metadata is stored in Supabase. XLSX and CSV exports are generated as conversion downloads and are not added to the EPUB library.

Site analytics

The public website uses GoatCounter to measure page visits. The analytics integration is separate from PDF conversion and document storage.

Open-source transparency

The application code and service configuration are available in the public GitHub repository. Privacy questions and technical issues can be reported through GitHub Issues.
