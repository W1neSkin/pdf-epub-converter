PDF conversion features

Choose a visual EPUB for reading or structured XLSX and CSV files for working with document data.

Fixed-layout EPUB

Every PDF page is rendered as a page image to preserve its original appearance. An invisible positioned text layer keeps text selectable.

Readable Excel workbook

XLSX export creates one worksheet per PDF page. Narrative text is displayed normally, while detected table rows use bordered cells, practical column widths and wrapped text.

CSV table extraction

Download all detected tables in one CSV file or a ZIP containing one UTF-8 CSV file per table. The extractor supports digital PDFs and OCR fallback for scanned documents.

Library and browser reader

Converted EPUB books can be saved to a personal library and opened in the built-in reader. Fixed-layout pages automatically fit the available reader width.

Free plan limits

The current free plan accepts PDF files up to 50MB and 50 pages. A free account is required for conversion and library access.
