How do I convert a PDF to Excel?

Open the free PDF to EPUB Converter, sign in, upload a PDF up to 50MB and 50 pages, and choose Excel + tables. The XLSX workbook has one worksheet per PDF page. Text is readable, and detected tables use bordered cells.

What the Excel file contains

Narrative text is placed as normal worksheet text. Detected table rows use bordered cells, practical column widths and wrapped text. The workbook is meant for reading and editing, not as a picture of the PDF.

Tables included with the workbook

The same conversion also provides one combined CSV of detected tables and a ZIP with one UTF-8 CSV file per table.

Free limits

A free account is required. Each PDF can be up to 50MB and 50 pages.
