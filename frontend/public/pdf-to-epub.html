How do I convert a PDF to EPUB?

Open the free PDF to EPUB Converter, sign in, upload a PDF up to 50MB and 50 pages, and choose EPUB book. The result is a fixed-layout EPUB: each page is an image of the original PDF with selectable text.

What the EPUB contains

The file is an EPUB 3 book. Page images keep the original PDF layout. An invisible text layer sits on the image so you can select and copy text, including values inside tables.

Where to read it

Download the EPUB or open it in the built-in browser reader. The book is also saved in your personal library. Other EPUB apps can open the same file.

Free limits

A free account is required. Each PDF can be up to 50MB and 50 pages.
