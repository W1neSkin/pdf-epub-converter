How do I extract tables from a PDF to CSV?

Open the free PDF to EPUB Converter, sign in, upload a PDF up to 50MB and 50 pages, and choose Excel + tables. Download one combined CSV of every detected table, or a ZIP with one UTF-8 CSV file per table. Scanned pages can use OCR.

Which CSV to download

Use the combined CSV when you want every detected table in one file. Use the ZIP when each table should stay in its own CSV. The same run also creates a readable XLSX workbook.

Scanned documents

Digital PDFs are read from their text layer. If a page has no usable text, OCR can read the scan and look for table rows. Complex or photographed tables may still need a manual check.

Free limits

A free account is required. Each PDF can be up to 50MB and 50 pages.
